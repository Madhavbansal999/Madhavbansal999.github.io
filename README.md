# Madhav Bansal — professional website

Static, responsive portfolio website with Schema.org ProfilePage/Person JSON-LD. No paid services or dependencies required.

## Publish free on GitHub Pages
1. Create a free GitHub account, or sign in.
2. Create a PUBLIC repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html` and `robots.txt` to the repository root.
4. Go to Settings → Pages, select Deploy from a branch, `main`, `/ (root)` and Save.
5. Wait for GitHub Pages to publish at `https://YOUR-USERNAME.github.io/`.
6. Add that URL to Linktree and your other professional profiles.
7. Optionally verify the website in Google Search Console and request indexing.

The site uses no images until an authentic, approved portrait is supplied. No contact details, nickname, or residential address are included. Google structured data does not guarantee a Knowledge Panel.
